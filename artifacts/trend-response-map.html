Recipe-wise Trend

The page finds the recipe parameter by itself (the one with alphanumeric values), splits the shift into recipe runs, and plots every numeric parameter in Highcharts with the runs shaded on the time axis. It uses the same logic as the new component code, run on the attached API response.

Drag across the chart to zoom. Hover to see the time, the recipe and each parameter's value. Picking a recipe shows only that recipe's runs.

Recipe runs

How the new logic works

  1. Find the recipe. Any selected parameter with a value containing a letter (such as CP500) is treated as the recipe. The rest are numeric trends. This works for any number of selected parameters.
  2. Clean the rows. Rows are sorted by time and repeated timestamps keep the last row, so each x value appears once.
  3. Build recipe runs. Consecutive rows with the same recipe form one run: { recipe, from, to }. A recipe that comes back later gets a second run.
  4. Draw. Each run becomes a shaded, labelled x-axis plot band. Each numeric parameter gets one series per run, linked together so the legend shows one entry per parameter and the line breaks at each recipe change. Limit lines span the visible range. The tooltip shows the recipe at the hovered time.
  5. Filter. Picking a recipe keeps only its runs and sets the x-axis to their range.
