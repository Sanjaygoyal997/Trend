Response shape

The envelope is fixed. Each row always has dateAndTime, plus one key per selected parameter ID. More parameters means more keys per row. A longer date or shift range means more rows.

Flow through the current code

  1. getMultiParameterTrendAnalysis checks that equipment, date and shift are selected, then calls the API with allSelectedParameters (demo mode falls back to [1384, 1385]).
  2. transformApiToChartData makes one series per selected ID by reading row[paramId], converting it with Number(), and dropping anything not finite. Alarm points get a red triangle marker.
  3. prepareChartConfig builds one y-axis per parameter (alternating left and right), one line series per parameter, and dashed upper and lower limit lines from stasticsAlarms.
  4. Result for this file: parameter 1 is drawn as a line. Parameter 2 shows in the legend with an empty axis. The 92 repeated timestamps stay in the series as duplicate x values.
